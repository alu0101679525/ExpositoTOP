# Recomendador Turístico con Ventanas de Tiempo (TOPTW)

Bienvenido al portal de documentación técnica del proyecto **ExpositoTOP**.

Este sitio web unifica toda la información relativa al desarrollo, funcionamiento y arquitectura de la solución algorítmica para el problema TOPTW, aplicando el paradigma *Docs-as-Code*.

## Contenido del Portal
* **Manual de Usuario:** Instrucciones de compilación y ejecución del código.
* **Algoritmo GRASP:** Explicación detallada de la metaheurística implementada.
* **Registro de Decisiones:** Listado de los cambios arquitectónicos y refactorizaciones aplicadas para la mejora de calidad (SonarQube).

Utiliza el menú de navegación para explorar las diferentes secciones.
